There are several modes, and only one is applied for one position of the chip on the line. Every bounded stretch of the line contains finitely many mode transitions. The mode transitions are decided by the current text, as a finite list of positions to the right of the chip. At a transition position, the new mode applies from that position on.

A generated text provides rules to edit the right of the chip, the same types of edit from the "reverse logic" folder. These rules are parameterized by the chip's current position and its active mode. They can do mathematically continuous or discrete edits to the line. A continuous edit places elements whose position depends on the chip's position; it is updated at every step of the chip, like a drag (Example 3 of "reverse logic"). Edits by a text never change the left side of the chip, the chip's position included. An edit of a text that is refused (for example, removing something that is not on the line) is skipped, and the text keeps running.

This text is generated by a machine designed to solve optimization problems. Because it cannot perfectly solve the optimization in a single pass for every scenario, it dynamically generates a new text when it decides to. It decides when it is relevant to generate a new text and how much time does it allow itself for a run, depending on its available CPU resources defined by the user. The time spent generating is outside of this system: the new text applies from the position the chip is at when the new text is installed.

When a new text is generated, all the edits made by the previous text are reversed (using the code in the "reverse logic" folder), without changing anything on the left side of the chip, the chip's position included. The right side of the chip becomes what it would be if the edits of the previous text had never happened, adapted where the left side requires it (for example, with the rule "if element A, then element B 2 units on the right", an element A just on the left of the chip keeps an element B on the right). An element that straddles the chip is cut at the chip. The edits of the user that require a reversed edit are reversed too. The rules of the new text are then applied.
