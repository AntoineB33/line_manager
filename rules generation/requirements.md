There are several modes, and only one is applied for one position of the chip on the line. Every bounded stretch of the line contains finitely many mode transitions.

A generated text provides rules to edit the right of the chip, the same types of edit from the "reverse logic" folder. These rules are parameterized by the chip's current position and its active mode. They can do mathematically continuous or discrete edits to the line.

This text is generated by a machine designed to solve optimization problems. Because it cannot perfectly solve the optimization in a single pass for every scenario, it dynamically generates a new text when it decides to. It decides when it is relevant to generate a new text and how much time does it allow itself for a run, depending on its available CPU resources defined by the user.

When a new text is generated, all the edits made by the previous text are reversed (using the code in the "reverse logic" folder), without changing anything on the left side of the chip. The rules of the new text are then applied.
