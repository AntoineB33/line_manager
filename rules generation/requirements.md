A chip advances along a continuous one-dimensional track containing various elements. The system state is defined by the chip's position and one of some modes, where the spatial distance between consecutive mode transitions is strictly positive to prevent infinitely frequent switching.

A generated text provides rules to append new elements to the track ahead of (to the right of) the chip. These rules are parameterized by the elements already on the track, the chip's current position, and its active mode.

This text is generated by a machine designed to solve optimization problems. Because it cannot perfectly solve the optimization in a single pass for every scenario, it dynamically generates a new text when necessary. When switching to a new text, any unreached elements previously placed to the right of the chip are discarded (using the code in the "reverse logic" folder), and the rules of the new text are applied.
